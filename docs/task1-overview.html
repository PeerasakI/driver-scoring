Quality controls

Sanitization

  • "-", blank, null token → None
  • "0.000" → 0.0 ไม่ใช่ missing
  • Y/N, 1/0 และ true/false → boolean

Pydantic validation

  • Vehicle ID ต้องไม่ว่าง
  • Timestamp ต้อง timezone-aware
  • Lat/lon และ non-negative metrics อยู่ในช่วงที่ถูกต้อง

Resilience

  • Source มาไม่ครบยังรันได้ใน warn mode
  • Bad row ไม่หยุด valid rows
  • Append rerun ไม่เพิ่ม exact duplicates

Requirement compliance check

Compliant = implement และตรวจสอบได้ครบ; Compliant with conditions = logic รองรับ แต่ supplied input หรือ external condition ยังไม่ครบ; Not compliant = ยังไม่มี implementation หรือหลักฐานขัดกับ requirement.
