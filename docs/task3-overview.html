2. Methodology เมื่อไม่มี labelled ground truth

วิธีหลักคือ literature-informed rule-based composite และ implement robust_zscore เป็น unsupervised challenger

normalized_risk = clip((observed − safe) / (severe − safe), 0, 1)
penalty_points = normalized_risk × effective_weight × 100
trip_score = 100 − Σ penalty_points

3. Data-grade behavior

Grade A · Driver Risk Score

ใช้ high-frequency CAN/GPS evidence: speed, harsh braking, harsh acceleration, speed smoothness และ night exposure

Grade B · Speed Behavior Index

ใช้ maximum speed, average speed และ speed variability เท่านั้น ไม่สร้าง harsh events จาก sparse GPS

Always-null engine

Task 2 ใช้ gps_gap_fallback และส่งเป็น Grade B จากนั้น Task 3 จึงคืน Speed Behavior Index โดยไม่ตีความ speed=0 ว่า engine-on

Entity limitation: source data ไม่มี driver_id จึง aggregate ที่ vehicle_id ซึ่งเป็น vehicle score/driver proxy เท่านั้น รถที่มีหลายคนขับจะไม่สามารถแยกบุคคลได้
